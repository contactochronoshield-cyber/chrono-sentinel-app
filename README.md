# 🤖 Chrono Sentinel App — AI Node Network

Aplicación oficial para la red de nodos distribuidos de **Sentinel IA**, equipada con integración nativa al motor de seguridad de **Chrono Shield Networks**.

---

## 🛡️ Integración con Chrono Shield Networks

Esta aplicación incluye el módulo cliente `sentinel_firewall_client.py`, el cual conecta los nodos de IA con la API REST local de Chrono Shield (`http://127.0.0.1:8080`).

* **Sincronización P2P de Amenazas:** Cuando la IA de un nodo identifica un vector de ataque o canal de exfiltración, reporta la firma al firewall local y a la red global de nodos.
* **Respuesta Dinámica:** Bloqueos automáticos ejecutados a nivel de DNS e Inspección Profunda de Paquetes (DPI) en milisegundos.
